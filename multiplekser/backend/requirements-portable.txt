# Runtime hook PyInstallera dla pkg_resources (pyi_rth_pkgres.py, uruchamiany zawsze gdy
# cokolwiek w drzewie zaleznosci importuje pkg_resources) laduje przy nowszym setuptools (>=70)
# jego zvendorowany kod (jaraco.text/platformdirs pod pkg_resources.extern), ktorego PyInstaller
# nie potrafi poprawnie spakowac - .exe buduje sie bez bledu, ale pada natychmiast po
# uruchomieniu (ModuleNotFoundError: backports / ImportError: platformdirs). Znany,
# udokumentowany problem PyInstaller+setuptools>=70 - najprostszy pewny fix to starszy
# setuptools w SRODOWISKU BUDOWANIA (nie wplywa na kod aplikacji ani na wdrozenie Docker).
setuptools<70
