# Multiplexer

Wewnętrzne narzędzie firmy **Dampol Investment** zamieniające papierowe/skanowane wydawki
materiałowe (Elektryka, Hydraulika) w gotowy plik importowy do Comarch Optima — przez OCR (AI),
automatyczne wykrywanie działu, dopasowanie do katalogu produktów i generowanie receptury.

Pełny opis, instrukcja uruchomienia i dokumentacja: [`multiplekser/README.md`](multiplekser/README.md).
